# Biruntha R — Portfolio

A responsive personal developer portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `biruntha_portfolio` folder in VS Code.
3. Open `index.html` with the VS Code Live Server extension (or open the file directly in a browser).

## Included
- Dark/light theme toggle and floating navigation
- Two rotating hero role titles
- Single user-controlled soft-tech instrumental track (`assets/audio/smart-technology-penguinmusic.mp3`)
- Responsive layout and scroll reveal animations
- Education orbit with rotating technology labels
- SmartAttendance and SmartBillz project showcase with previous/next screenshot controls
- Three certificate cards
- Live GitHub public profile/repository statistics and contribution graph (requires internet access)
- Contact form that opens the visitor's email app; WhatsApp shortcut

GitHub statistics are fetched from GitHub's public API when the site is online. The contribution graph is loaded from a public graph image service. Music does not autoplay; click the Music control to start or pause it.
